Genome Analysis of Rhodiola yunnanensis

A plant genomics and bioinformatics project exploring publicly available sequencing data from NCBI.

About the project

This project follows a published genome study of Rhodiola yunnanensis, from raw sequencing data preparation to genome assembly and annotation.

Analysis workflow

  1. Project setup
  2. Sequencing data download and validation
  3. SRA to FASTQ conversion

  7. Assembly evaluation
  8. Genome annotation
