Genome Analysis of Rhodiola yunnanensis

Genome assembly and annotation of a medicinal plant species

1. Project overview

This project focuses on the genome analysis of Rhodiola yunnanensis using publicly available sequencing data from the National Center for Biotechnology Information (NCBI).

The analysis follows the workflow described in a published genome study, covering raw sequencing data preparation, quality assessment, genome survey, genome assembly, assembly evaluation, and genome annotation.

2. Research objectives

  • Prepare and assess publicly available sequencing data.
  • Estimate genome characteristics using k-mer analysis.
  • Perform genome assembly and evaluate assembly quality.
  • Annotate repetitive sequences and protein-coding genes.
  • Compare the analysis results with the published genome study.

3. Data sources

  • NCBI BioProject: PRJNA1353568
