# Genome Assembly and Annotation of *Rhodiola yunnanensis*

## About the project

This project explores the genome of *Rhodiola yunnanensis* using publicly available sequencing data from NCBI.

The analysis follows the workflow of a published genome study, starting from raw sequencing data and progressing through genome assembly and annotation.

This is also part of my learning process in plant genomics and bioinformatics.

## Objectives

- Download and prepare raw sequencing data.
- Perform quality control.
- Estimate genome characteristics.
- Perform genome assembly.
- Evaluate assembly quality.
- Perform genome annotation.
- Compare the results with the published study.

## Workflow

Raw data → Quality control → Genome survey → Genome assembly → Assembly evaluation → Scaffolding → Genome annotation

Software and tools used in this project will be added as the analysis progresses.
